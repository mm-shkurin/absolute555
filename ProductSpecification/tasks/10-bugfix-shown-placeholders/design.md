# 10 — bugfix: заглушки там, где картинки уже есть

Источник: `ProductSpecification/FixPlan-2026-09-06.md`, пачка A (правки 6, 10, 11-а, 14,
20, 21) плюс правка 15 (сплющенная карточка в профиле продавца).

## Дефект

Одна причина на семь мест: компонент рисует серую заглушку, хотя адрес картинки уже
доехал до него или лежит на проводе одним полем дальше. Заглушка допустима только там,
где данных нет вовсе.

## Решение

**Общий компонент `shared/ui/Cover`** — картинка при адресе, `Placeholder` при `null`.
Сегодня та же развилка написана трижды: `Gallery.Shot` (своя), `ListingCard` (заглушка
как рамка вокруг `img`), и пять мест, где её нет вовсе. `Gallery.Shot` переезжает в
`Cover`; межфичевый импорт запрещён линтом, поэтому дом — `shared/ui`.

Аватар развилку уже имеет — `shared/ui/Avatar`. Второго компонента не заводить.

## Состав

| Место | Что сейчас | Что станет |
|---|---|---|
| `myListings` | `Placeholder` всегда | обложка из `car.preview_photo_url`; поля в `MyListingWire` нет — добавить |
| `offers/OfferRow` | `Placeholder`, `photo_url` в объекте есть | обложка из `photo_url` |
| `moderation/ComplaintsPage` | `Placeholder` + `complaintView` роняет аватар автора | обложка карточки и аватар жалобщика |
| `moderation/QueueList` | `Placeholder` | обложка; найдено сверх плана тем же grep |
| `chats/DialogList` | пустой `span.avatar` | `Avatar` собеседника |
| `chats/Conversation` | `Placeholder` | превью объявления |
| `SiteHeader` | пустая ссылка-круг | `Avatar` вошедшего; `Session.avatarUrl` при входе не заполняется |
| `listing/SellerBlock` | пустой `div.avatar` | аватар продавца; найдено сверх плана |
| `sellerProfile` | `PersonHead` без `avatarUrl` | проброс `seller.data.avatar_url` |
| `sellerProfile/.cards` | сетка вокруг `ListingGrid` | обёртку убрать, `ListingGrid` — уже сетка |

## Правило, которое называется здесь

Сетку не заворачивают в сетку. `ListingGrid` — сетка; нужно другое число колонок —
проп `columns`, а не внешний `grid-template-columns`.

## Что не входит

Заглушки лендинга, мастера продажи и карты замеров: там данных нет по существу —
это макетные поверхности, а не потерянные адреса.
