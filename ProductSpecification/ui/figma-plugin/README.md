# Плагин: перенос дизайна в Figma

Строит в файле Figma переменные, текстовые стили, компоненты и экраны из наших токенов.

## Почему плагин, а не API

Figma REST API **не создаёт слои**. На запись открыты только комментарии и dev-ресурсы;
эндпоинта «создай фрейм» не существует ни с каким токеном. Переменные пишутся через
`POST /v1/files/:key/variables`, но это тариф Enterprise, а у нашего токена нет и скоупов:

```
GET /v1/files/YcB68XINy3k28fBcjq3UYM/variables/local
403 {"message":"Invalid scope(s): ..."}
```

Плагин выполняется внутри приложения и имеет полный доступ к документу. Это единственный
способ построить дизайн программно.

## Как запустить

1. `node build.mjs` — собирает `src/*.js` в `dist/code.js`.
2. Figma (десктоп) → меню **Plugins → Development → Import plugin from manifest…**
3. Выбрать `manifest.json` из этой папки.
4. Открыть нужный файл → **Plugins → Development → Абсолют — дизайн-система**.

Повторный запуск обновляет существующие переменные и стили, а не плодит копии: коллекция
и стили ищутся по имени. Экраны при этом создаются заново — старые удалить вручную.

## Что появится в файле

**Страница «Абсолют — система»**

- Коллекция переменных `Абсолют` с двумя режимами: **Светлая** и **Тёмная**. Тема
  переключается на выделенном фрейме в панели справа — это режим коллекции, а не второй
  набор стилей.
- 12 текстовых стилей: заголовки, цены, текст, кнопка, два моношиных.
- Компоненты: кнопка (основная и вторичная), чип, ярлык статуса, бейдж на фото.

**Страница «Абсолют — экраны»**

- Лента, десктоп 1280: шапка, колонка фильтров, четыре карточки.
- Карта замеров, десктоп 1280: схема кузова векторами, легенда, список панелей.

Всё на автолейауте. Макет из абсолютных координат ломается от первой правки текста,
и чинит его потом человек руками по одному слою.

## Чего плагин не делает

- **Не переносит все 26 экранов.** Собраны два, на которых видна вся система; остальные
  добавляются функцией на экран в `src/screens-*.js` по образцу. Механически перегонять
  весь мокап в Figma смысла мало: кликабельный прототип уже есть в `../mockups/index.html`,
  а Figma нужна как место для правки макета руками.
- **Не рисует фотографии.** Вместо снимков — утопленные слоты с подписью. Настоящую
  штриховку в Figma пришлось бы делать векторной сеткой, а слой всё равно заменят фото.
- **Не тянет значения из репозитория.** Плагин не читает файлы проекта, поэтому токены
  продублированы в `src/tokens.js`. Расхождение с `frontend/src/styles/tokens-light.css` —
  ошибка; первоисточник — CSS, потому что он исполняется.

## Шрифты

Golos Text и JetBrains Mono должны стоять в системе. Если их нет, плагин отработает,
проставит размеры и трекинг, но начертания оставит по умолчанию и скажет об этом в
уведомлении.
