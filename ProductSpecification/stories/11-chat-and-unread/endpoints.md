# Чат покупателя и продавца, непрочитанные - API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/chat/dialogs | Список диалогов: последнее сообщение и непрочитанные |
| GET | /api/v1/chat/dialogs/{dialog_id}/messages | Лента одного диалога, страницами |
| POST | /api/v1/chat/dialogs/{dialog_id}/messages | Написать сообщение |
| POST | /api/v1/chat/dialogs/{dialog_id}/read | Отметить прочитанным по список идентификаторов |
| GET | /api/v1/chat/unread | Одно число для бейджа в таб-баре |
| WS | /api/v1/chat/ws | Живой поток своих диалогов |

## Notes

- **Диалог заводится вместе с предложением по цене**, а не отдельным вызовом. Второе
  предложение по тому же объявлению попадает в тот же разговор: диалог один на пару и
  объявление.
- **Участник или никто.** Чужой диалог отвечает `404`, а не `403`: `403` подтверждает,
  что разговор существует, а вместе с ним — что по объявлению кто-то торгуется.
- **Системные строки пишет сервер.** Автор помечен как система, и прислать такую строку
  клиент не может: иначе «предложение принято» пишет кто угодно.
- **Прочтение посообщенно.** Тело запроса — список идентификаторов; отмечаются только
  чужие сообщения этого диалога, свои игнорируются молча. Повторная отметка не двигает
  момент прочтения.
- **`GET /chat/unread` — одно число**, а не список: бейдж в таб-баре рисует его, и
  выдача диалогов ради одного числа была бы страницей на каждый переход между экранами.
- **WebSocket авторизуется при подключении** и слушает только диалоги подключившегося.
  Соединение без токена закрывается, а не оставляется открытым и немым.
- **`/task/sse/{sale_car_id}` перестаёт быть открытым.** Сейчас поток слушает любой, кто
  знает идентификатор объявления. Теперь — вход и владение объявлением; чужому тот же
  `404`, что и на неопубликованное.
- Проданное объявление не закрывает диалог: встречу назначают и после сделки.
