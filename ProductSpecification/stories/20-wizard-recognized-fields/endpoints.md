# Ручки истории 20

Одна, и та по просьбе фронта (`interview.md`, раздел ACTION).

## POST /api/v1/sale_car/{sale_car_id}/decode-vin

Распознать характеристики по VIN, который продавец вписал руками на экране
«документ прочитали, VIN — нет» (`autofill.state = undecoded`).

- Тело: `{"vin": "XTA21074051234567"}`
- 202 `StsAccepted` — та же форма, что у POST /{id}/sts: задача в очереди, исход по
  SSE `/api/v1/task/sse/{sale_car_id}` и полем `autofill` в выдаче объявления.
- 422 `VIN_MALFORMED` — строка не той формы; проверяется до постановки задачи.
- 409 `LISTING_FROZEN` — правка разрешена только в draft и rejected.
- 404 — чужое или несуществующее объявление. 401 — без токена.

Контракт: `api-specs/sale_car_sts.yaml`.

Отдельная ручка, а не PATCH с побочным эффектом: правка полей и запуск распознавания —
разные действия.

Исходы прежние минус один: `unreadable` здесь невозможен по построению — читать нечего,
снимка нет. VIN, по которому машина не нашлась, — `undecoded`.

Номер кузова (`GB6-1000952`) ручка не принимает: в нём закодирован завод, а не машина,
и расшифровывать по нему нечего. Японская машина без VIN заполняется руками.
