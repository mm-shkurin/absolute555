# История 19 — Гигиена слоёв: ORM из роутеров, HTTPException из сервисов

Решения приняты по коду, 2026-09-02. Ветка `features/seller-rating`.

## Scope

- Убрать из роутеров импорты ORM. Все двенадцать известных нарушений были одного рода:
  роутер тянул класс модели **ради подсказки типа**, а не ради запроса.
- Словарь состояний объявления и предложения вынести из ORM-модуля: набор статусов нужен
  роутеру, схеме и таблице одинаково, а хранение — только таблице.
- Псевдоним «кто зовёт» вместо импорта модели пользователя в каждом маршруте.
- Свести `scripts/repo-rules-baseline.json` к нулю: список известных нарушений
  разбирается, а не растёт.

Не входит:

- Перенос запросов из роутеров в сервисы: запросов в роутерах нет — гейт ловил импорты.
- `HTTPException` из сервисов: гейт таких не находит, правило соблюдается.
- Разбор `app/features/*/api/*_view.py` на отдельный слой: вид — часть транспорта.

## Key Architectural Decisions

DECISION: **Словарь состояний живёт вне четырёх слоёв области** —
`app/features/listing/statuses.py` и `app/features/offer/statuses.py`. Перечисление
статусов принадлежит всем слоям сразу: роутер фильтрует по нему, схема его публикует,
таблица его хранит. Модель импортирует его и продолжает отдавать имена наружу, поэтому
сервисы, для которых объявление и его статусы — один предмет, ничего не переписывают.

DECISION: **`CurrentUser` и `SignedInUser` — псевдонимы зависимостей**, живущие в
`app/permissions/`. Роутеру нужен вызывающий, а не строка таблицы; до этого ORM
импортировалась в восьми файлах ради одной подсказки типа.

DECISION: **Где аннотация не встаёт по синтаксису — зависимость без подсказки типа.**
`Annotated`-параметр не может стоять после параметра со значением по умолчанию, а
переставлять параметры маршрутов ради красоты значит трогать двадцать сигнатур без
нужды. В пяти файлах остался `current_user=Depends(...)`.

DECISION: **Baseline сводится к нулю, а не переписывается.** Храповик работает в обе
стороны: когда нарушение чинят, скрипт требует убрать строку — иначе список превращается
в кладбище, по которому никто не ходит.
