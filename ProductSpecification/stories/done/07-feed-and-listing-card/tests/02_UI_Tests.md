# UI Tests — Лента и карточка объявления

UI = n/a.

Экран ленты и четыре её состояния, колонка фильтров, счётчик и карточка — фронтовая
полоса; она ведётся отдельной нарезкой (`ProductSpecification/stories.md`). Здесь
строится выдача, на которой те экраны стоят.

## Сценарии карточки (цикл покрытия, итерация 5)

Исполняемая копия: `frontend/src/features/listing/__tests__/ListingPage.test.tsx`.

```gherkin
Feature: Карточка объявления

  Scenario: Гость нажимает «Предложить цену» — его ведут на вход, а не прячут кнопку
    Given гость открыл карточку Lexus GS
    When нажимает «Предложить цену»
    Then начинается вход, предложение не уходит

  Scenario: Покупатель предлагает цену с пробелами — продавцу уходит число
    When покупатель вводит «1 750 000» и отправляет
    Then продавцу уходит 1750000, и покупатель видит «Предложение отправлено»

  Scenario: Машину уже продали — отказ показан в шторке словами
  Scenario: Покупатель раскрывает телефон продавца
  Scenario: Продавец скрыл телефон — кнопка выключена, связь через чат
  Scenario: Жалоба уходит только с причиной

  Scenario: Продавец открыл торг — вошедший покупатель видит чужие предложения
    Given продавец включил «Показывать предложения покупателям»
    When вошедший покупатель открывает карточку
    Then он видит предложения по цене

  Scenario: Торг закрыт — покупатель за чужими предложениями не ходит
  Scenario: Владелец видит управление вместо торга и снимает объявление
  Scenario: Владелец с неполной картой видит, сколько панелей не замерено
  Scenario: Проданная машина — действия выключены, видна отметка «Продано»
  Scenario: Объявление сняли — страница говорит, что его не нашли
```
