# Load Tests — Лента и карточка объявления

Load = n/a на этот заход.

`ProductSpecification/ExpectedLoad.md` называет ленту тем самым путём чтения, на
который приходится подавляющая часть запросов, — единственным местом проекта, где
форма запроса имеет значение. Но объём мал: сотни живых объявлений и десятки новых в
день, ни один заявленный профиль нагрузки не задействован.

Форму запроса держит проверка индексов в `04_Infrastructure_Tests.md`. Два сценария
про время ответа записаны в `tier3/03_Load_Tests.md` и не строятся.
