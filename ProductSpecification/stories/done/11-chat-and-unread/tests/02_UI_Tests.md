# UI Tests — Чат

UI = n/a. Экран чатов и бейдж в таб-баре строятся фронтовой нарезкой.

## Сценарии фронта (добавлены по аудиту покрытия)

Исполняемые копии: `frontend/src/shared/api/backend/__tests__/chatFrame.test.ts`,
`frontend/src/features/chats/api/__tests__/chatsApi.test.ts`,
`frontend/src/shared/query/__tests__/retryPolicy.test.ts`.

```gherkin
Feature: Переписка в реальном времени

  Scenario: Вторая сторона получает сообщение в открытую переписку без перезагрузки
    Given собеседник написал в диалог
    When сервер присылает кадр живого потока
    Then сообщение попадает в этот диалог с текстом собеседника

  Scenario: Список переписок показывает машину, собеседника и последнюю строку
    Given у покупателя переписка с продавцом по Lexus GS
    When он открывает чаты
    Then строка называет машину, цену, собеседника и последнее сообщение

  Scenario: Переписка по заявке называет заявку и бюджет, а не машину
    Given переписка открыта откликом на заявку без марки с бюджетом 3 000 000 ₽
    When покупатель открывает чаты
    Then строка называется «Заявка: без марки» и показывает бюджет

  Scenario: Одна переписка у двух сторон — своё сообщение справа только у автора
    Given покупатель написал «Торг уместен?»
    When переписку открывают покупатель и продавец
    Then у покупателя сообщение своё, у продавца — чужое

  Scenario: Снятое объявление сразу показывает «не найдено», без повторов
    Given объявление сняли с публикации
    When экран его запрашивает
    Then отказ показывается сразу, запрос не повторяется
```
