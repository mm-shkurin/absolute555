# UI Tests — Карта окрасов

Исполняемые копии: `frontend/src/shared/thicknessMap/__tests__/BodySchematic.test.tsx`,
`frontend/src/shared/thicknessMap/__tests__/geometry.test.ts`.

```gherkin
Feature: Карта окрасов кузова
  Как покупатель, я хочу видеть на схеме кузова, какие панели перекрашены,
  чтобы знать, что проверить на осмотре

  Background:
    Given продавец замерил капот (110 мкм, заводская) и правое переднее крыло (320 мкм, перекрашено)

  Scenario: Перекрашенное правое крыло окрашено цветом перекраса во всех проекциях
    When покупатель открывает карту
    Then каждое вхождение правого переднего крыла на схеме — цвета перекраса

  Scenario: Незамеренная панель видна как «не замерено», а не заводская
    When покупатель открывает карту
    Then задняя левая дверь окрашена цветом «не замерено»

  Scenario: Клик по крылу на правом борту выбирает это крыло
    When покупатель нажимает на правое переднее крыло на правом борту
    Then выбрано правое переднее крыло

  Scenario: Выбранная панель подсвечена во всех своих вхождениях
    Given выбран капот
    Then капот подсвечен в каждой проекции, где он нарисован

  Scenario: Легенда подписывает цвета числами порогов
    When покупатель открывает карту
    Then легенда читается «перекрашено 200–499» и «шпаклёвка от 500»
```
