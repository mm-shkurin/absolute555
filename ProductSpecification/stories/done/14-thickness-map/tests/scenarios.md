# 14 — сценарии

## Tier 1 (без чего история не работает)

- **api-01** продавец записывает замер панели и получает карту с этой панелью
- **api-02** повторная запись той же панели перезаписывает замер, а не добавляет второй
- **api-03** покупатель читает карту опубликованного объявления
- **api-04** замер без фотографии прибора отклонён
- **api-05** панели, которой нет в наборе, не существует
- **api-06** значение вне диапазона 1..3000 отклонено
- **api-07** карта из всех тринадцати панелей помечена полной
- **api-08** карточка объявления несёт сводку замеров
- **api-09** убранный замер уводит карту из полной
- **sec-01** запись замера требует входа

## Tier 2 (закалка того, что уже работает)

- **api-10** чужое объявление не находится
- **api-11** замер правится и после публикации объявления
- **api-12** файл, который не изображение, отклонён
- **api-13** черновик чужого продавца не отдаёт карту
- **api-14** пороги: 150 — заводская, 300 — перекрас, 700 — шпаклёвка
- **api-15** объявление без замеров отдаёт пустую карту, а не 404
- **inf-01** один замер на панель, гарантирует база

## Tier 3 (записан, не строится)

- история версий замера и аудит правок — правило «перезапись» решено в интервью
- срок жизни подписанной ссылки на фотографию прибора — недетерминированное время
- параллельная запись двух панелей — механизм уже проверен на галерее
