# Карта толщиномера - API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/sale_car/{sale_car_id}/thickness | Карта замеров объявления |
| PUT | /api/v1/sale_car/{sale_car_id}/thickness/{panel} | Записать или перезаписать замер панели |
| DELETE | /api/v1/sale_car/{sale_car_id}/thickness/{panel} | Убрать замер панели |

## Notes

- **Панель — часть пути, а не тело.** Набор фиксирован (13 значений enum), и `PUT` по
  адресу панели идемпотентен: повторный вызов перезаписывает замер, а не заводит второй.
  Отсюда же берётся уникальность «один замер на панель», которую держит БД.
- **Запись — `multipart/form-data`**: `value_um` формой и `photo` файлом. Как и галерея,
  и по той же причине: фотография экрана прибора приезжает файлом, а не base64.
- **Значение — целое, `1..3000` мкм.** Ноль и отрицательное значение прибор не показывает,
  а три тысячи — заведомо выше любой шпаклёвки; за границами `422`.
- **Статус панели считает сервер**: `factory` (< 200), `repaint` (200-499), `filler`
  (>= 500). Клиент красит панель по `status`, а не по числу.
- **`is_complete`** — все 13 панелей измерены. Признак отдаётся вместе с картой и в
  карточке объявления; фильтр по нему — история 15.
- **Карточка и детальная выдача несут сводку** `thickness`: `measured_panels` и
  `is_complete`. Отдельного вызова ради двух чисел не заводится.
- **Чужое объявление — `404`**, как и везде: `403` подтвердил бы, что идентификатор живой.
  Чтение карты неопубликованного объявления посторонним — тот же `404`.
- **Удаления карты целиком нет.** Панель убирается по одной; «стереть всё» — кнопка,
  которой нет в макете.
