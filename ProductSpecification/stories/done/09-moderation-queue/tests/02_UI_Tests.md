# UI Tests — Модерация: очередь, отклонение с причиной, жалобы

UI = n/a.

Экраны «Очередь модерации» и «Жалобы» нарисованы в `ui/mockups/index.html` и строятся
фронтовой нарезкой. Здесь — выдачи, на которых они стоят.

## Сценарии фронта (цикл покрытия, итерация 3)

Исполняемые копии: `frontend/src/features/moderation/api/__tests__/moderationQueue.test.ts`,
`moderationDecisions.test.ts`.

```gherkin
Feature: Очередь модерации

  Scenario: Продавец заполнил карту замеров — модератор видит полную карту
    Given продавец замерил все 13 панелей и отправил объявление
    When модератор открывает очередь
    Then в строке и в карточке проверки карта 13 из 13, а не «не заполнена»

  Scenario: Объявление без замеров помечено «без карты»
  Scenario: Машина под заказ помечена в очереди как «под заказ»
  Scenario: Вкладки называют числа сервера
  Scenario: Продавец без закрытых сделок назван новым
  Scenario: На объявление пожаловались — строка помечена жалобами

Feature: Жалобы и решения модератора

  Scenario: Модератор видит жалобу с причиной словами и текстом покупателя
    Given покупатель пожаловался на цену-приманку
    When модератор открывает жалобы
    Then карточка называет машину, число жалоб, причину словами и когда пожаловались

  Scenario: Жалоба необоснованна — модератор её отклоняет, объявление остаётся
  Scenario: Снять с публикации по жалобе можно только с причиной для продавца
  Scenario: Отклонение без комментария отправляет только причину
  Scenario: Модератор публикует объявление
  Scenario: Повторная жалоба того же покупателя — отказ сервера текстом
```
