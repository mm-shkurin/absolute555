# UI Tests — Модерация: очередь, отклонение с причиной, жалобы

UI = n/a.

Экраны «Очередь модерации» и «Жалобы» нарисованы в `ui/mockups/index.html` и строятся
фронтовой нарезкой. Здесь — выдачи, на которых они стоят.

## Сценарии фронта (цикл покрытия, итерация 3)

Исполняемые копии: `frontend/src/features/moderation/api/__tests__/moderationQueue.test.ts`,
`moderationDecisions.test.ts`.

```gherkin
Feature: Очередь модерации

  Scenario: Продавец заполнил карту замеров — модератор видит полную карту
    Given продавец замерил все 13 панелей и отправил объявление
    When модератор открывает очередь
    Then в строке и в карточке проверки карта 13 из 13, а не «не заполнена»

  Scenario: Объявление без замеров помечено «без карты»
  Scenario: Машина под заказ помечена в очереди как «под заказ»
  Scenario: Вкладки называют числа сервера
  Scenario: Продавец без закрытых сделок назван новым
  Scenario: На объявление пожаловались — строка помечена жалобами

Feature: Жалобы и решения модератора

  Scenario: Модератор видит жалобу с причиной словами и текстом покупателя
    Given покупатель пожаловался на цену-приманку
    When модератор открывает жалобы
    Then карточка называет машину, число жалоб, причину словами и когда пожаловались

  Scenario: Жалоба необоснованна — модератор её отклоняет, объявление остаётся
  Scenario: Снять с публикации по жалобе можно только с причиной для продавца
  Scenario: Отклонение без комментария отправляет только причину
  Scenario: Модератор публикует объявление
  Scenario: Повторная жалоба того же покупателя — отказ сервера текстом
```

## Страницы кабинета (цикл покрытия, итерация 4)

Исполняемые копии: `frontend/src/features/moderation/__tests__/*Page.test.tsx`.

```gherkin
Feature: Модератор разбирает очередь, не уходя со страницы
  Scenario: Первая карточка очереди открыта на проверку сразу
  Scenario: Выбор строки открывает её на проверку
  Scenario: Модератор публикует объявление — запрос уходит по выбранной машине
  Scenario: Отклонить без причины нельзя — кнопка отправки неактивна до выбора причины
  Scenario: Очередь пуста — страница говорит, что всё проверено
  Scenario: Решение не принято сервером — модератор видит причину

Feature: Модератор решает по совокупности жалоб
  Scenario: Жалобы на одно объявление собраны в одну карточку
  Scenario: «Отклонить жалобы» закрывает все жалобы карточки, а не одну
  Scenario: Снятие с публикации начинается с выбора причины для продавца
  Scenario: Жалоб нет — страница говорит, что всё разобрано
  Scenario: Жалобы не загрузились — модератор видит причину и может повторить

Feature: Заявки в поставщики
  Scenario: Заявка показывает роль словами, зачем и что добавил человек
  Scenario: Одобрение выдаёт роль — сервер получает решение
  Scenario: Отказ без текста причины отправить нельзя
  Scenario: Разобранная заявка показана без кнопок решения
  Scenario: Вкладка без заявок называет, чего нет
  Scenario: Переход на вкладку одобренных запрашивает у сервера одобренные

Feature: Витрина поставщика проходит проверку
  Scenario: Модератор видит условия витрины — страны, марки, срок
  Scenario: Правка опубликованной витрины показана поверх прежних полей
  Scenario: Публикация витрины уходит на сервер
  Scenario: Отказ витрине только с причиной — причина уходит на сервер
  Scenario: Витрина без срока доставки так и названа
  Scenario: Очередь пуста — страница объясняет, где ждут заявки на роль

Feature: Сводка кабинета показывает, куда идти сегодня
  Scenario: Плитки называют числа сервера и ведут в раздел
  Scenario: Сводка не загрузилась — модератор видит это и может повторить

Feature: Люди площадки
  Scenario: Строка называет роль и вход словами и помечает закрытый доступ и ушедших
  Scenario: Поиск уходит по нажатию «Найти», а не на каждую букву
  Scenario: Людей больше страницы — «Дальше» открывает вторую
  Scenario: Никого не нашлось — так и написано
  Scenario: Список не загрузился — предложение повторить

Feature: Карточка человека и доступ
  Scenario: Карточка называет роль, вход, число объявлений и жалоб
  Scenario: Закрыть доступ без причины нельзя — экран просит причину до запроса
  Scenario: Доступ закрыт с причиной — причина уходит на сервер
  Scenario: У закрытого доступа видна причина и кнопка «Вернуть доступ»
  Scenario: Сервер отказал в действии — модератор видит, что запись не в его власти
  Scenario: Журнал действий виден администратору
  Scenario: Модератору журнал не показывается
  Scenario: Ушедший человек помечен, закрывать нечего
```
