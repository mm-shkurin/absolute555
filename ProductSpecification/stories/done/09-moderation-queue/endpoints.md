# Модерация: очередь, отклонение с причиной, жалобы - API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/moderation/queue | Очередь: ожидают, с жалобами, разобранные сегодня |
| GET | /api/v1/moderation/counts | Числа на вкладках |
| POST | /api/v1/sale_car/{id}/reject | Отклонение: ярлык обязателен, текст нет (расширяется) |
| POST | /api/v1/sale_car/{id}/complaints | Пожаловаться на объявление |
| GET | /api/v1/moderation/complaints | Жалобы: открытые и разобранные |
| POST | /api/v1/moderation/complaints/{id}/dismiss | Признать жалобу необоснованной |
| POST | /api/v1/moderation/listings/{id}/unpublish | Снять с публикации по жалобам |

## Notes

- **Очередь отдаёт страницу, как лента.** `{items, total, page, size}`: семь объявлений
  сегодня и триста в плохую неделю — одна и та же выдача.
- **Порядок очереди — самые давние первыми.** Иначе объявление, отправленное утром,
  ждёт дольше вечернего, и очередь перестаёт быть очередью.
- **Вкладка выбирается параметром `tab`:** `waiting` (статус `moderation`),
  `complained` (опубликованные с открытыми жалобами), `handled_today` (решения этого
  модератора за сегодня).
- **Причина отклонения — ярлык плюс необязательный текст.** Ярлык обязателен и берётся
  из перечисления; свободный текст без ярлыка не даёт ответа на вопрос «за что чаще
  всего отклоняют», а он и есть то, ради чего очередь разбирают руками.
- **Жалоба — от вошедшего, одна на объявление.** Вторая от того же человека — отказ:
  «2 жалобы» на карточке должно означать двоих людей, иначе модератор читает шум.
- **Пожаловаться можно только на опубликованное и не на своё.**
- **Снятие с публикации возвращает объявление в `rejected` с причиной** и закрывает все
  открытые жалобы по нему одним решением. `withdrawn` выглядел бы как действие самого
  продавца, и он никогда не узнал бы, что править.
- **Переход `published → rejected` добавляется в таблицу переходов** (история 4). Это
  единственное изменение жизненного цикла в этой истории.
- **Автоматики нет.** Никакое число жалоб не снимает объявление само.
- Разбор `catalog_suggestions` (истории 3 и 6) сюда не входит — это другая очередь.
