# UI Tests — Рейтинг продавца и публичный профиль

Экраны ведёт фронтовая полоса. Здесь названо только то, чем бэкенд их питает:
блок продавца в карточке, строка очереди модерации, поля can_review и review_id
на экране офферов, публичный профиль. Сценарии Selenium пишутся во фронтовой
полосе против этих же вызовов.
