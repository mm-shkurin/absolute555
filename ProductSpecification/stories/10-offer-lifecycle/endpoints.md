# Офферы: отзыв, истечение, автоотклонение при продаже - API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/offer/my | Свои офферы, стороной: `side=received` или `side=sent` |
| POST | /api/v1/offer/ | Сделать оффер (сужается: только опубликованное, не гость) |
| PATCH | /api/v1/offer/{id}/status | Принять или отклонить — владелец объявления |
| POST | /api/v1/offer/{id}/withdraw | Отозвать свой оффер, пока он ждёт ответа |

## Notes

- **`/offer/my` разделяется параметром `side`.** Экран показывает два таба, и одна общая
  выдача заставляла бы фронт делить её по владельцу объявления, которого в ней нет.
- **Шесть статусов вместо трёх:** `pending`, `accepted`, `rejected`, `withdrawn`,
  `expired`, `car_sold`. Экран пишет «отозван вами», «истёк» и «машину продали» разными
  словами, потому что это разные события: одно сделал покупатель, второго не сделал
  никто, третье сделал продавец с другим человеком.
- **Отзыв — только свой и только `pending`.** Отозвав, покупатель может прислать новый:
  иначе отзыв означал бы запрет на торг по этому объявлению навсегда.
- **Принятие — одна транзакция:** объявление уходит в `sold`, остальные живые офферы по
  нему — в `car_sold`. Разорванная надвое, эта операция оставляет либо проданную машину с
  висящими офферами, либо закрытые офферы при непроданной машине.
- **Истечение — периодическая задача ARQ**, а не вычисление при чтении. Ленивое
  истечение оставляет в базе `pending`, и продавец примет оффер, которого по правилам уже
  нет. Срок — трое суток, читается из настроек: это гипотеза о поведении людей, а не
  свойство предметной области.
- **Истёкший оффер не принимается** — попытка отвечает отказом, а не тихо оживляет его.
- **Оффер только на опубликованное объявление.** Сейчас он принимается и на черновик, и
  на снятое с публикации — торг за то, чего нет в ленте.
- **Гость не торгуется.** Чужие офферы он уже не видит; создание оставалось открытым, и
  это несогласованность, а не решение.
- Разница «на 170 000 ниже» считается на экране из цены объявления и цены оффера — в
  выдаче её нет.
