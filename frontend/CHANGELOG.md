# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версия в `package.json`
не выпускается отдельно: разделы идут по спринтам, номера историй — из
`ProductSpecification/stories.md`.

## [Unreleased] — 2026-09-14

### Added
- Ручные тест-кейсы по всем экранам: `docs/testing/` (8 файлов, шаблон с ID, шагами,
  ожидаемым результатом и статусом).
- Семантические токены затемнения, штриховки и тени (`styles/tokens-light.css`).
- `CHANGELOG.md`, раздел README о запуске в Docker Compose, решениях и своих скриптах.

### Changed
- Перечитывание объявления при распознавании СТС — с нарастающей паузой (4 с × 1,5, не
  реже 30 с), без наложения запросов, с отменой при уходе с шага.
- Доступ к `window` и `sessionStorage` — только через `shared/lib/browser.ts`.
- Связанное состояние галереи и формы замера сведено в один объект.
- `.gitignore` переписан под Vite: `dist/`, `.env`, папки Capacitor.

### Fixed
- Форма повторного отклика поставщика заполняется прежней ценой.
- Модератор видит карту замеров и привоз в выдаче.
- VIN уходит распознаванию объектом; отказ 4xx внутри `send` не повторяется.
- Суммы с пробелами между разрядами принимаются, как в подсказках полей.

- Роль поставщика сохраняется в сессии; фото авторов в отзывах.
