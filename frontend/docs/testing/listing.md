# Карточка объявления, продавец и поставщик

Ручные проверки страницы `/listings/:id` (история 8 и 7 — режимы гостя, покупателя и
проданной машины; телефон; шторка предложения — история 10; жалоба — история 9; галерея —
история 5; «кто решил» — история 22), публичного профиля продавца `/sellers/:id` (история 12)
и страницы поставщика `/suppliers/:id` (история 16). Адрес фронта — `<FRONT_URL>`.
Окружение, учётные записи и шаблон — в [README.md](README.md).
