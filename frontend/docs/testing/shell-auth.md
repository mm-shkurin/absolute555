# Каркас: лендинг, вход, закрытый доступ, навигация

Ручные проверки общего каркаса SPA: развилка корня `/` (гость — лендинг, вошедший —
лента), страница `/how-it-works`, возврат от Яндекса `/auth/callback`, экран
`/access-closed`, шапка, нижняя панель вкладок, тема и неизвестный адрес. Окружение,
учётные записи и легенда — в [README.md](README.md).
