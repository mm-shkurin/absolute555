# Лента и канал «Под заказ»

Ручные проверки публичной ленты `/feed` (фильтры, сортировка, дозагрузка, счётчик, пустые
состояния — истории 7 и 15) и ленты «под привоз» `/import` с тремя видами содержимого
(история 17). Адрес фронта обозначен `<FRONT_URL>`. Окружение, учётные записи и шаблон —
в [README.md](README.md).

### TC-FEED-001 — Лента показывает карточки и счётчик объявлений

| Статус | Not run |
