# Мастер продажи

Ручные проверки мастера размещения объявления: вход с `/sell` и `/sell?kind=import`,
шесть шагов (`Фото СТС`, `Характеристики`, `Цена и контакты`, `Фотографии`,
`Карта замеров`, `Отправка`), снимок СТС и автозаполнение, пометка распознанных полей,
ручной ввод VIN, галерея фото, отправка на модерацию и продолжение черновика из
«Мои объявления». Черновик сохраняется на каждом переходе «Дальше»; после создания адрес
становится `/sell/<id>`. Окружение, учётные записи и шаблон — в [README.md](README.md).
