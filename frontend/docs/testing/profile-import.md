# Профиль, роль поставщика и заявки на привоз

Ручные проверки в браузере: свой профиль `/my/profile` (имя, фото, выход), заявка на роль
`/my/supplier-application`, витрина поставщика `/my/supplier-profile`, заявка покупателя
`/import-requests/new` и её страница `/import-requests/:id` с откликами. Один шаг — одно
действие; ожидаемый результат — видимый текст, элемент или адрес. Удаление учётной записи
в интерфейсе фронта не найдено (кнопки в исходниках нет), поэтому случая на него нет.
Окружение, учётные записи и шаблон — в [README.md](README.md).
