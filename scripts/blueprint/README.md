# Схема кузова из чертежа

Геометрия карты замеров (`frontend/src/features/thickness/components/geometry/`) не
пишется руками: она снимается с чертежа `ProductSpecification/ui/blueprints/body-blueprint.svg`.
Рисованные на глаз координаты дают коробки, похожие на машину, — и расходятся с
чертежом на каждой правке.

Конвейер:

```bash
W=<рабочая папка>
python scripts/blueprint/rasterize.py ProductSpecification/ui/blueprints/body-blueprint.svg $W 3
python scripts/blueprint/cells.py $W        # линии делят лист на замкнутые области
python scripts/blueprint/paths.py $W        # области собираются в панели, контуры упрощаются
python scripts/blueprint/emit.py $W frontend/src/features/thickness/components/geometry
```

`paths.py` держит две таблицы, которые и есть вся ручная часть:

- `PANELS` — какие области чертежа принадлежат какой панели. Область, не попавшая ни в
  одну панель, становится деталью: фара, фонарь, стекло, колесо — они обводятся, но не
  красятся, потому что это проёмы, а не окрашиваемый металл.
- `VIEWS` — где на чертеже лежит проекция, куда она едет на схеме и на сколько
  поворачивается. Перёд и зад на чертеже лежат боком.

Номера областей зависят от порога площади: понизив его, вы перенумеруете всё. Поэтому
назначения хранятся якорями — точкой внутри области, а не её номером.

## Борт: панели по именам слоёв

`body-side-left.svg` нарисован в макете так, что каждая панель — замкнутая фигура со
своим именем. Здесь угадывать нечего, заливка не нужна:

```bash
python scripts/blueprint/named_side.py ProductSpecification/ui/blueprints/body-side-left.svg $W2
```

Соответствие имени слоя и кода панели — таблица `NAMED` в самом скрипте. Всё, что в неё
не попало, становится деталью: стёкла, фары, фонари, зеркала, колёса, ручки — они
обводятся, но не красятся, потому что это проёмы, а не окрашиваемый металл.

Пути двух источников сливаются перед `emit.py`: борт берётся отсюда, остальные проекции —
из общего чертежа. Правый борт — отражение левого, не отдельный источник: панели те же,
а вторая копия координат разошлась бы с первой на первой правке обвода.

Так это и должно расти дальше: перед, зад и вид сверху пока с общего чертежа и заметно
грубее борта. Нарисованные тем же способом, они пойдут тем же скриптом.
