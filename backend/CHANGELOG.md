# Журнал изменений бэкенда

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии не

## [Unreleased] — ветка `features/paint-map`

### Добавлено
- Чтение экрана толщиномера через GigaChat с подтверждением значения продавцом; ответ
  кэшируется в Redis по хэшу снимка.
- Чат: переписка открывается откликом поставщика на заявку, со страницы витрины и прямым
  обращением в витрину.
- Отзыв по переписке; фото витрины поставщика.
- Правка опубликованной витрины через повторную проверку, фото квадратом.
- Полоска окрасов на карточке объявления в ленте.
- Тесты бэкенда по пользовательским историям.

### Изменено
- **Деплой:** запросы к GigaChat проверяют TLS. Серверу нужен `GIGA_CA_BUNDLE` — путь к
  корневому сертификату Минцифры; без него распознавание СТС и прибора отвечает
  «не прочитано». Таймауты GigaChat читаются из настроек.
- **Деплой:** адреса Yandex OAuth берутся только из окружения — `YANDEX_AUTHORIZE_URL`,
  `YANDEX_TOKEN_URL`, `YANDEX_INFO_URL` обязательны (значения в `infra/.env.example`);
  без них приложение не стартует. Пороги толщиномера и размеры снимка СТС — настройки
  с прежними значениями по умолчанию.
- Тесты падают, а не пропускаются, когда нет Redis, базы или справочника; гонки вынесены
  в `tests/test_listing_race.py` с таймаутом.
- Линтер ruff (`ruff.toml`); неиспользуемые импорты удалены.
- CI требует покрытия изменённых строк (`diff-cover --fail-under=60` против `dev`), а не
  порога по всему репозиторию; tesseract ставится в прогон.

### Исправлено
- Подтверждённое число со снимка помечается как чтение прибора.
- Фото опубликованной витрины проходят через модератора; витрина показывает фото и
  отвечает на сохранение.
- Настройки видимости объявления больше не замораживаются.
- Lexus GS 430 находится в справочнике, фильтре и на карточке.
- Три дыры, найденные тестами; замер покрытия учитывает потоки TestClient и greenlet'ы.
- Пул приложения сбрасывается вокруг теста потока событий.
