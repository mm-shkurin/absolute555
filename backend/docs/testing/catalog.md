# Каталог марок и моделей

Публичный справочник марок и моделей: список марок и модели одной марки. Обе ручки доступны без
входа. Окружение и формат ошибки — в [README.md](README.md).

### TC-CAT-001 — Список марок доступен без входа

| Поле | Значение |
|---|---|
| ID | TC-CAT-001 |
| Название | Список марок доступен без входа |
| История | 06 — Автозаполнение из СТС: привязка к справочнику |
| Описание | Фильтр ленты и мастер объявления получают марки до входа |
| Приоритет | High |
| Предусловия | Каталог засеян (`python -m app.data.seed_catalog`) |
| Тестовые данные | — |
| Шаги | 1. GET /catalog/brands, без Authorization |
| Ожидаемый результат | `200`, непустой массив; у каждого элемента поля `brand_id` (uuid), `slug`, `name_ru`, `name_en`, `is_popular` |
| Статус | Not run |
| Фактический результат | |

### TC-CAT-003 — Модели марки принадлежат только этой марке

| Поле | Значение |
|---|---|
| ID | TC-CAT-003 |
| Название | Модели марки принадлежат только этой марке |
| История | 06 — Автозаполнение из СТС: привязка к справочнику |
| Описание | Одноимённая модель другой марки (например, `Focus`) не попадает в чужой список |
| Приоритет | High |
| Предусловия | Каталог засеян |
| Тестовые данные | `<BRAND_1>`, `<BRAND_2>` — `brand_id` первых двух марок из GET /catalog/brands |
| Шаги | 1. GET /catalog/brands/<BRAND_1>/models<br>2. GET /catalog/brands/<BRAND_2>/models |
| Ожидаемый результат | Шаги 1–2: `200`, массив элементов с полями `model_id`, `brand_id`, `slug`, `name`<br>У всех моделей шага 1 `brand_id` = `<BRAND_1>`<br>Множества `model_id` шагов 1 и 2 не пересекаются |
| Статус | Not run |
| Фактический результат | |

### TC-CAT-004 — Модели несуществующей марки

| Поле | Значение |
|---|---|
| ID | TC-CAT-004 |
| Название | Модели несуществующей марки |
| История | 06 — Автозаполнение из СТС: привязка к справочнику |

| Ожидаемый результат | `404`, `code` = `BRAND_NOT_FOUND`, `message` = `Brand not found` |
| Статус | Not run |
| Фактический результат | |
