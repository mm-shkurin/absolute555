## 🎯 Описание

Absolute Backend API - это RESTful API для управления автосервисом, предоставляющее функционал для работы с автомобилями, записями на обслуживание, запчастями и интеллектуальной обработкой документов. Система поддерживает автоматическое распознавание данных из СТС, предсказание замены запчастей и управление пользователями с ролевой моделью доступа.

## 🛠️ Технологии

### 1. Авторизация
- **JWT (PyJWT)** - для генерации access и refresh токенов
- **OAuth 2.0** - интеграция с VK и Yandex для социальной авторизации
- **PKCE** - защита OAuth потоков
- **HttpOnly Cookies** - безопасное хранение токенов в веб-приложениях
- **Argon2/Bcrypt** - хеширование паролей

### 2. Работа с картами (автомобилями)
- **PostgreSQL + SQLAlchemy** - основная база данных для хранения информации об автомобилях
- **GeoAlchemy2** - работа с геоданными и координатами
- **Alembic** - миграции базы данных
- **MinIO/S3** - хранение файлов и изображений автомобилей
- Управление VIN-кодами, СТС, историей обслуживания

### 3. Работа с ML
- **GigaChat** - LLM для обработки текста и извлечения данных из документов
- **Tesseract OCR** - распознавание текста с изображений СТС
- **OpenCV** - обработка и улучшение изображений перед OCR
- **ChromaDB** - векторная база данных для семантического поиска
- **ONNX Runtime** - выполнение ML моделей (all-MiniLM-L6-v2) для эмбеддингов
- **Celery + Redis** - асинхронная обработка ML задач
- Функции: автоматическое декодирование VIN из СТС, предсказание замены запчастей на основе истории обслуживания

### Дополнительные технологии
- **FastAPI** - веб-фреймворк
- **Celery** - фоновые задачи
- **Redis** - кеширование и очереди
- **Docker & Docker Compose** - контейнеризация

## 🚀 Установка

### Предварительные требования

- Python 3.12+
- PostgreSQL 17+
- Docker и Docker Compose
- Git

### Клонирование репозитория

```bash
git clone https://gitverse.ru/mm-shkurin/Absolute-api.git
cd Absolute-api
```

### Установка через Docker (рекомендуется)

1. Создайте файл `.env` в корневой директории проекта с необходимыми переменными окружения

2. Запустите проект:

```bash
docker-compose up -d
```

### Установка вручную

1. Создайте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения в файле `.env`

4. Выполните миграции базы данных:

```bash
alembic upgrade head
```

## ⚙️ Запуск

### Запуск через Docker Compose

```bash
docker-compose up -d
```

Приложение будет доступно на порту, указанном в переменной окружения `APP_PORT` (по умолчанию 8000).

### Запуск вручную

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### Запуск Celery worker

```bash
celery -A app.celery_worker.celery_app worker --loglevel=INFO
```

## 📝 Конфигурация

Создайте файл `.env` в корневой директории проекта со следующими переменными:

- Настройки базы данных (PostgreSQL)
- Настройки Redis
- Настройки MinIO/S3
- JWT секреты
- OAuth ключи (VK, Yandex)
- GigaChat API ключ
- И другие необходимые параметры
